# 镜端初始页面方案

> 状态：批次一、批次二均已实施并通过回归验收（2026-11-18）。
> 范围：镜端新增初始页面（待机首页）、App 新增首页与「我的」页、Core API 配套扩展。

## 1. 布局框架

```
┌──────────────────────────────────────────────┐
│ ● 手机未连接·配对码 482913              V/S  │  ← 顶部：连接状态 + 品牌
│                                              │
│ ┌────────┐                    ┌────────┐     │
│ │ 天气   │                    │ 趋势   │     │
│ │ 1×2    │     （镜面留白）    │ 1×2    │     │
│ ├────────┤    中央照人区域     ├────────┤     │
│ │ 待办   │                    │ 周计划 │     │
│ │ 1×2    │                    │ 1×2    │     │
│ └────────┘                    └────────┘     │
│                                              │
│           让每一次发力可见                     │  ← 激励语（无句号）
│           11月17日 周一 · 21:30               │  ← 日期时间同行
└──────────────────────────────────────────────┘
```

- **无中央 GO 按钮**：初始页为纯展示页，中央留白即镜面照人区域。
- **模块网格**：左右两列各 4 个行位，模块档位为 `1×1`（占一行）或 `1×2`（占两行），模块选择、档位、排序在手机端「我的」页编排。
- **配色与风格**：沿用现有设计语言——`#090B0A` 深底、`#D9FF43` 酸性黄绿强调、网格辉光背景、Bahnschrift 显示字体。
- **激励语**：默认文案「让每一次发力可见」，按时段轮播，置于日期时间上方。
- **日期时间**：同行居底，日期弱化、时间突出，时间需远距离可读（大字号）。
- **连接状态**：未配对时常显「● 手机未连接 · 配对码 482913」；已连接后弱化为绿点 +「手机已连接」并隐藏配对码。配对码采用固定开发码。

## 2. 页面流转

```
App 切到「训练」页 ──▶ 镜端自动进入训练配置/HUD（沿用 M2 跟随模式）
App 离开训练页   ──▶ 镜端自动回到初始页
```

- 镜端**保留** setup-panel 的独立训练配置入口作兜底（手机不在身边时可用）。
- 初始页是新的默认首页，位于 setup-panel 之前。

## 3. 模块清单与实施批次

| 模块 | 内容 | 数据链路 | 批次 |
|------|------|---------|------|
| 天气 | 温度 / 天气现象 / 湿度 / 今日温度区间 | Core 代理外部天气 API（Open-Meteo），统一拉取+缓存；仅镜端展示，App 首页不显示 | 一 |
| 训练趋势 | 近 7 天按天聚合训练次数/时长，SVG 柱状图，今日柱高亮 | 复用 Core 历史会话表按天聚合，不加表 | 一 |
| 今日待办 | 任务清单，完成态划线，显示完成进度（如 2/4） | Core 新增 `todos` 表；App 首页增删改与勾选，镜端只读 | 二 |
| 本周训练计划 | 周一至周日训练安排（动作+组次），今日项高亮 | Core 新增 `weekly_plans` 表；App 首页编辑，镜端只读 | 二 |

**边界约定**：训练计划是结构化动作训练安排；今日待办是生活化轻量事项（喝水、拉伸、睡眠），纯勾选，不与训练流程联动。

## 4. 数据同步设计

```
              ┌──────────┐
   App 首页 ──▶│  Core API │◀── 镜端初始页
   （读写）    │  SQLite   │   （只读）
              └─────┬────┘
                    │ WebSocket 推送
                    ▼
              镜端实时刷新（复用 M2 通道）
```

- **唯一数据源在 Core**：待办、计划、布局配置由 App 写入、Core 落库、WebSocket 推送镜端，两端永远一致。
- **天气由 Core 代理**：镜端与 App 均从 Core 获取，避免双端各自请求外部 API。
- **镜端为只读展示**：所有编辑操作在 App 完成。
- 镜端刷新页面后从 Core 重新拉取，自动恢复布局与数据。

## 5. App 侧结构（四页）

| 页面 | 内容 |
|------|------|
| **首页（新增初始页）** | 固定单列行动流：今日计划（上一项/下一项切换）→ 近 7 天训练趋势 → 今日待办；天气不在 App 展示，周计划通过「调整本周计划」进入独立编辑页 |
| 训练（现有） | 不变；切入该页时镜端自动跟随进入训练 |
| 历史（现有） | 不变 |
| **我的（新增）** | 设备与偏好总览：当前连接、镜端布局摘要、深色模式、配对设备、关于与解除配对；完整模块编排进入二级编辑页 |
