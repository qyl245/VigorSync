# 离线 3D 姿态稳定与遮挡预测规则

## 1. 目标

离线报告中的 3D 骨架优先保证“不展示明显错误的姿态”，其次才追求完整人体。

- 可靠关节：正常显示
- 不确定关节：降低透明度
- 遮挡关节：可短时预测，预测部分使用虚线
- 长时间遮挡：隐藏对应骨骼，不强行补全

## 2. 置信度分级

| 状态 | 可见度 | 显示 |
|---|---:|---|
| 高置信 | `>= 0.65` | 正常实线 |
| 中置信 | `0.35 - 0.65` | 半透明 |
| 低置信 | `< 0.35` | 隐藏并断开 |

2D 视频骨架和 3D 骨架使用同一置信度阈值。

## 3. 时间缺口预测

- 1–5 帧：PCHIP/线性插值
- 6–15 帧：PCHIP 或边界外推预测
- 超过 15 帧：停止预测，输出缺失
- 所有补齐点标记为 `predicted=true`
- 预测骨骼以虚线显示

## 4. 侧视远侧肢体镜像预测

单相机侧视时，远侧肢体容易被躯干遮挡，且遮挡时间可能超过 15 帧，时间插值无法覆盖。

因此对 `pushup + side_left/side_right` 增加解剖学镜像预测：

- `side_left`：用左侧近侧肢体预测右侧远侧肢体
- `side_right`：用右侧近侧肢体预测左侧远侧肢体
- 反射平面由左右肩连线确定
- 远侧根关节保持观测值，后续关节通过近侧肢体向量反射生成

当前规则配置：

```text
side_left
  arm: near 11-13-15 -> far 12-14-16
  leg: near 23-25-27-29-31 -> far 24-26-28-30-32

side_right
  arm: near 12-14-16 -> far 11-13-15
  leg: near 24-26-28-30-32 -> far 23-25-27-29-31
```

触发条件：

- 近侧肢体关节均为高置信
- 远侧肢体除根关节外存在低于 `0.65` 的关节
- 远侧根关节位置有效

预测关节必须继续经过骨长约束和地面锚定，并在报告中明确显示预测的骨骼段名称。

## 5. 骨长约束

- 骨长目标只从高置信、非预测帧统计中位数
- 父子关节均为高置信：完整修正
- 中置信或预测关节：最大修正 `0.03 m`，半幅修正
- 低置信关节：不修正

## 6. 支撑与地面锚定

支撑点：

- 深蹲：双脚
- 俯卧撑：双手 + 双脚

规则：

- 只使用高置信、非预测支撑点更新锚点
- 支撑点不可用时保持上一个有效锚点
- 锚点逐帧跟随支撑点，避免真实下蹲/撑起被限速拖慢导致脚底脱离地面
- 位移小于 `0.005 m` 时保持锚点，抑制关键点抖动
- 单帧位移超过 `0.08 m` 时按 `0.08 m` 跟随，过滤关键点闪跳
- 地面固定为 `Y=0`
- 地面法向量偏离重力方向超过 8° 时回退到 MediaPipe 稳定 Y 轴
- 左右轴偏离默认横轴超过 18° 时回退到默认横轴

## 7. 渲染规则

- 观测骨骼：实线
- 中置信观测：半透明实线
- 预测骨骼：对应侧颜色虚线
- 预测关节：空心虚线圆
- 预测状态提示格式：

```text
遮挡预测：右肩–右肘、右肘–右手、右髋–右膝、右膝–右踝
```

- 固定提示：

```text
虚线部分为遮挡期间的姿态预测
```

## 8. 当前局限

- 单相机无法恢复真实的长遮挡深度
- 镜像预测假设近侧与远侧肢体接近对称
- 跑步、跨步等非对称侧视动作不能直接使用对称镜像
- 多视角或学习型时序 3D 模型属于后续独立阶段

## 9. 过程指标适用视角

- 重心前后漂移、深蹲前倾偏移和稳定性只在侧视/斜侧机位参与异常分级
- 左右对称性只在正面/背面机位参与异常分级
- 不适用机位仍显示曲线，但状态固定为“仅趋势”，不绘制关注/异常阈值线
- 姿态固定偏移与过程波动分别计算：
  - 偏移：Rep 底部附近窗口内的中位角
  - 稳定性：去除该 Rep 中位姿态后，相对角度的标准差
- 当前阈值仍为工程暂定值，`expert_calibrated=false`

## 10. 动作专项过程指标

- 深蹲专项：
  - 底部膝角：左右髋–膝–踝角均值，用于观察下蹲深度
  - 膝部内扣轨迹：膝相对踝向身体中线的横向偏移比例
- 俯卧撑专项：
  - 底部肘角：左右肩–肘–腕角均值，用于观察下放深度
  - 手肘外张角度：正面投影中上臂相对同侧躯干的夹角
- 通用节奏结构：
  - 逐 Rep 展示总时长
  - 拆分下蹲/下放与起身/推起阶段
  - 以 Rep 时长变异系数判断整组节奏稳定性
- 专项指标标记为 `diagnostic_only`，状态显示“专项观察”，不直接生成正式问题卡
- 深度指标只在侧视/斜侧机位可评估；膝轨迹和手肘外张只在正面/背面机位可评估

## 11. P2 探索过程指标

- Rep 动作轮廓：将每个 Rep 的主关节角曲线按起止时间归一化到 0–100% 动作进度
- 动作平滑度：轮廓定幅、定时后计算三阶导数均方根，并映射为 0–100 平滑度指数
- 左右动作同步性：对左右主关节角曲线做带时序偏移的相关分析，输出 0–100 同步指数
- P2 指标仅标记为“专项观察”，不生成问题卡，也不设置产品异常结论
- 左右同步性只在正面/背面机位参与观察，侧视只显示趋势
